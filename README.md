
## Portal académico de demonstração

Abrir `dist/portal.html` através de um servidor estático. Inclui perfis exploráveis de Secretaria, Professor e Encarregado de educação; alunos, turmas, avaliações, presenças, propinas simuladas, horários e mural de comunicados. Os dados são fictícios e guardados apenas no localStorage do navegador. O botão «Repor dados de demonstração» recupera os exemplos iniciais. Não tem autenticação, controlo de acesso no servidor, pagamentos reais nem ligação aos registos da instituição. Os perfis servem exclusivamente para apresentar a experiência do futuro produto.

O website público inclui animações de entrada repetidas em cada passagem pelas secções. As preferências de movimento reduzido são respeitadas.
